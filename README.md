# Хроники — архив ролевых миров

Локальное веб-приложение для заметок настольных ролевых игр, базы знаний и интерактивных карт миров. Работает без сборки и без сервера приложений.

## Сайт на GitHub Pages

Проект настроен на автоматическую публикацию через GitHub Pages из ветки `main`. После включения Pages и первого успешного запуска workflow сайт будет доступен по адресу:

**https://baraaoi.github.io/Dnd_kaif/**

Workflow находится в `.github/workflows/deploy-pages.yml`. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации, если GitHub не включит его автоматически при первом запуске.

## Запуск локально

Откройте `index.html` в современном браузере или запустите локальный веб-сервер из этой папки:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Стартовый пароль: **12345**.

## Возможности

- база знаний с категориями, поиском и фильтрами по миру;
- кнопка «Добавить историю»: интерфейс не ограничивает длину вставляемого текста; модель очищает скопированные элементы интерфейса, выделяет хронологию, определяет мир и извлекает персонажей и места;
- выделенные события, персонажи, города и другие места добавляются в базу знаний; новые места получают точки на карте уже существующего мира, а дубликаты отфильтровываются;
- можно вручную выбрать мир, если автоматическое определение не подошло; для ИИ-разбора обязателен API-ключ: без него форма не сохраняет историю автоматически, чтобы не выдавать необработанный текст за результат ИИ; ручное добавление записи остаётся доступным отдельно;
- ручное добавление заметок и существующих миров сохранено; приложение не придумывает новые миры или локации;
- интерактивная карта уже добавленных миров с точками интереса и масштабированием;
- Yandex AI Studio включён провайдером по умолчанию: для анализа нужен API-ключ с областью `yc.ai.languageModels.execute`, Folder ID каталога и доступная модель (по умолчанию `yandexgpt-5.1`); также доступны Gemini и произвольный OpenAI-совместимый API;
- API-ключ вводится в интерфейсе пользователя и не вшит в репозиторий. При включённом сохранении он хранится в localStorage браузера; полный текст истории отправляется выбранному провайдеру, а тарификация/квоты определяются аккаунтом этого провайдера;
- LM Arena — платформа оценки моделей, не источник API-ключа для вызова моделей из сайта; для встраивания используется API самого провайдера.
- данные миров и записей хранятся в `localStorage` браузера и не синхронизируются между устройствами; фактический объём хранения ограничен браузером.

## Важно о защите

Экран пароля — простая клиентская блокировка для личного/демонстрационного использования, а не серверная аутентификация: пароль и логика проверки видны в исходниках, а данные остаются в браузере. Не используйте это как защиту конфиденциальных данных или как замену серверному входу.
